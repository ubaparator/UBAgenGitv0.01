Render Environment içinde DISCORD_BOT_TOKEN doğru olmalı; bot Discord sunucusuna davet edilmiş olmalı. Render loglarında 401, Gateway veya slash sync hatasını kontrol et. Servis yeniden başladığında uptime sıfırlanır.

GitHub Actions işi 401 / 403 / 404 hatası veriyor

GH_TOKEN doğru depoya erişmeli ve repository dispatch iznine sahip olmalı. Token encode testi yapılana kadar gerekli değildir. Actions sekmesinde workflow hatasını aç.

FFmpeg / ASS / font hatası

GitHub Actions logunda ilk FFmpeg hatasına bak. Bu sürüm ASS/SRT yakma yapar; fontları otomatik paketleme henüz garanti edilmez.

Rclone / Drive / MEGA / çıktı temizliği

RCLONE_CONFIG INI biçiminde doğru olmalı. RCLONE_REMOTE_PATH yalnızca geçici klasör olmalı; temizlik workflow'u bu klasörde 2 saatten eski MP4 dosyalarını siler. Rclone ayarı yoksa çıktı kısa ömürlü Actions artifact olarak saklanır.

Servis uyuyor veya kota doluyor

Render ücretsiz servisleri uyuyabilir ve GitHub Actions süre/kota sınırlarına tabidir; 7/24 çalışma garantisi yoktur. Keepalive ping uyku davranışını kesin olarak engellemez.
