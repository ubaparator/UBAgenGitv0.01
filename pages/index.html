Bilinen sorunlar ve kontroller

Discord bot çevrimdışı / slash komutları görünmüyor

DISCORD_BOT_TOKEN doğru mu? Bot sunucuya davetli mi? Render loglarında 401/Privileged intent/Gateway hatası var mı? Uygulama açılırken komut senkronizasyonu tamamlanmış mı? Komutlar bazen Discord istemcisinde gecikmeli görünebilir.

GitHub Actions işi başlamıyor (401/403/404)

GH_TOKEN geçerli mi, doğru depoya erişebiliyor mu ve Contents: Read and write izni var mı? repository_dispatch event adı encode_request ile eşleşmeli. Actions bu depoda etkin olmalı.

Video/altyazı indirilemiyor

Bağlantı doğrudan indirilebilir ve HTTP(S) olmalı. Discord ek bağlantıları süreli olabilir; çok büyük dosyalar veya giriş isteyen sayfalar başarısız olabilir. Bu ilk sürüm magnet/torrent indirmez.

FFmpeg / altyazı / font sorunu

Actions logundaki ffprobe ve FFmpeg hatalarını incele. ASS dosyasının kodlaması, font ailesi ve altyazı yolundaki özel karakterler sorun çıkarabilir. Font otomatik paketleme henüz yapılmıyor.

Rclone / Drive / MEGA / çıktı temizliği

RCLONE_CONFIG doğru INI içeriği mi ve remote adı desteklenen backend mi? MEGA için kullanılan rclone sürümünde backend bulunmaması sorun yaratabilir. RCLONE_REMOTE_PATH yalnızca geçici klasör olmalı: temizlik görevi 2 saatten eski MP4 dosyalarını siler.

Uyku, süre ve kota sınırları

Render ücretsiz servisleri uyuyabilir; 10 dakikalık ping 7/24 çalışma garantisi vermez. GitHub-hosted runner süre/kota sınırlarına tabidir. Cloud Run/Google Cloud bu mimaride kullanılmıyor.
